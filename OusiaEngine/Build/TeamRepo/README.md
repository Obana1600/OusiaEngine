# チームのプロジェクト

OusiaEngine で作るゲームのリポジトリです。ガイドは `Editor/` にあります。

- [エディターガイド](Editor/README.md)
- [スクリプトの書き方](Editor/Scripting.md)
- [スクリプト API リファレンス](Editor/Script-API.md)
- [シェーダとポストエフェクトの書き方](Editor/Shaders.md)

- `Editor/` … ビルド済みのエディタ（エンジンの担当の人だけが更新します）
- `Assets/` … シーン・スクリプト・画像など（みんなで作るもの）
- `ProjectSettings/` … Build Settings・レイヤー・製品の名前など
