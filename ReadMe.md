# ReadMe

## CG2 評価課題3

### 基本操作
- ImGui
  - 各オブジェクトの選択、生成、削除
  - オブジェクトのSRT操作
  - マテリアルのUVのSRT、色、ライティングモードの操作
  - 平行光源の色、方向、輝度の操作

- カメラ
  - ミドルボタン + ドラッグ -> 角度
  - ミドルボタン + ドラッグ + 左Shiftキー -> XY移動
  - ホイール -> Z移動


### 加点要素

#### 球の描画
- sphere.objを読み込んで描画しています。
- 扇状三角形分割を用いているため、三角面化を忘れていても描画できるようにしています。

#### Lambertian Reflectance
- ピクセルシェーダーでランバート反射の計算を行っています。
- ImGuiで方向、色、輝度を変更することができます。

#### Half Lambert
- 同じく、ピクセルシェーダーでハーフランバート反射の計算を行っています。
- 同じく、ImGuiで各パラメータを変更することができます。

#### UVTransform
- ImGuiでマテリアルのテクスチャのトランスフォームを変更することができます。

#### 複数モデルの描画
- ModelクラスとWorldTransformクラスをコンテナに格納しているため、複数のモデルを描画し独立したSRTの変更ができます。

#### Utah Teapotの描画
- teapot.objを読み込んで描画しています。

#### Stanford Bunnyの描画
- bunny.objを読み込んで描画しています。

#### MultiMesh対応
- Modelクラスでは、Meshクラスをコンテナに格納しているため、複数のメッシュを扱えるようになっています。

#### MultiMaterial対応
- 同じく、Materialクラスをコンテナに格納しているため、複数のマテリアルを扱えるようになっています。

#### Suzanneの描画
- Suzanneのようにマテリアルにテクスチャが貼られていない場合は、"white1x1.png"を使うようにしています。

#### Lighting方式の変更
- ImGuiで各マテリアルの"ライティング方式"を変更します。
- 各マテリアルごとにライティングモードを持たせ、ピクセルシェーダーに送りその値によって色の計算を行っています。
